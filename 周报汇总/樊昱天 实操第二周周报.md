**四、 遇到的问题与困难**

*   **技术问题：**
    *   WebSocket 握手阶段 Token 鉴权：前端 WebSocket 连接时无法像 HTTP 请求一样通过 Header 带 Token
    *   **已尝试的解决方案：** 通过 WebSocketInterceptor 在握手阶段从 URL query 参数中提取 Token 进行校验
    *   **需要帮助或待解决：** 无
*   **非技术问题：**
    *   Git 推送权限问题持续：本地改动能正常推送，但大文件/大量改动推送时仍偶发 403
    *   **已采取的措施：** 拆分 commits、控制单次推送规模
    *   团队协作中前后端接口字段定义不一致，联调时需反复沟通对齐
    *   **已采取的措施：** 编写前端对接指南，明确接口字段格式
