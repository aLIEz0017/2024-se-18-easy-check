## 一、总体架构：一库双端

本项目采用 **"一库双端"** 架构——一个 Vue3 项目，通过 Vue Router 的全局前置守卫根据用户角色自动跳转至对应视角。

```

├── main.js                 # 入口：创建 app、注册 router/pinia/element-plus
├── App.vue                 # 根组件：仅包含 <router-view />
├── style.css               # 全局样式
│
├── router/                 # 【共享】路由配置
│   ├── index.js            # 路由主文件：创建 router 实例 + 全局守卫
│   ├── routes.js           # 路由表定义（所有路由集中管理）

### 2.3 路由守卫逻辑（guard.js）

```javascript
// src/router/guard.js
// 全局前置守卫逻辑，由组员A和组员C协商确定后，组员A实现

export function setupRouterGuard(router) {
  router.beforeEach((to, from, next) => {
    const token = localStorage.getItem('token')
    const userRole = localStorage.getItem('userRole') // 'attendee' | 'organizer' | null

    // 情况1：访问开始界面或登录页 → 始终放行
    if (to.path === '/' || to.path === '/login') {
      return next()
    }

    // 情况2：访问需要登录的页面但未登录 → 跳转登录页
    if (to.meta.requiresAuth && !token) {
      return next('/login')
    }

    // 情况3：访问需要特定角色的页面但角色不匹配
    if (to.meta.role && to.meta.role !== userRole) {
      if (userRole === 'organizer') return next('/b/dashboard')
      if (userRole === 'attendee') return next('/c/hall')
      return next('/login')
    }

    // 情况4：其他情况放行
    next()
  })
}
```

### 2.4 路由守卫行为一览

| 当前状态 | 访问路径 | 跳转结果 |
|----------|----------|----------|
| 任意状态 | `/` | ✅ 正常显示开始界面 |
| 未登录 | `/login` | ✅ 正常显示登录页 |
| 未登录 | `/register-preferences` | 🔀 跳转 `/login` |
| 已注册临时登录(attendee) | `/register-preferences` | ✅ 正常显示偏好设置页 |
| 未登录 | `/b/dashboard` | 🔀 跳转 `/login` |
| 未登录 | `/c/hall` | ✅ 正常显示活动大厅（公开） |
| 未登录 | `/c/tickets` | 🔀 跳转 `/login` |
| 已登录(organizer) | `/login` | ✅ 正常显示（可手动退出登录） |

### 4.2 登录/注册页面（LoginView.vue）— 组员A

**路径**：`/login`

**功能**：
- 登录表单：用户名 + 密码 + 登录按钮
- 注册表单：用户名 + 密码 + 角色选择（参会者/举办方）+ 注册按钮
- 登录/注册切换 Tab

**组件结构**：
```
LoginView.vue
├── el-tabs (登录 / 注册)
│   ├── el-tab-pane (登录)
│   │   └── el-form
│   │       ├── el-input (用户名)
│   │       ├── el-input (密码)
│   │       └── el-button (登录)
│   └── el-tab-pane (注册)
│       └── el-form
│           ├── el-input (用户名)
│           ├── el-input (密码)
│           ├── el-radio-group (角色: 参会者/举办方)
│           └── el-button (注册)
```

**交互流程**：
1. 登录成功 → 调用 `authStore.login()` → 根据 role 跳转：
   - `organizer` → `/b/dashboard`
   - `attendee` → `/c/hall`
2. 注册成功 → 调用 `authStore.register()` 保存后端返回的临时 token，并按注册身份分支：
   - `attendee`（普通参会者）→ 跳转 `/register-preferences`，补充画像后回 `/login`
   - `organizer`（活动举办方）→ 不进入偏好设置页；清除临时登录态，提示"注册成功，请登录"，切换到登录 Tab

**调用的 API**：
- `POST /api/v1/auth/login`
- `POST /api/v1/auth/register`

### 4.2.1 注册后偏好设置页面（PreferenceSetupView.vue）— 组员A

**路径**：`/register-preferences`

**功能**：
- 仅注册身份为普通参会者（`role = attendee`）的首次注册流程会进入本页，依赖注册接口返回的临时 token。
- 活动举办方（`role = organizer`）注册后不进入本页，直接回登录界面。
- 选择性别：男 / 女 / 其他。
- 选择偏好标签：科技、电竞、音乐、学术等，至少选择 1 个。
- 提交成功后清除临时登录态，跳回 `/login` 让用户正式登录。

**组件结构**：
```
PreferenceSetupView.vue
├── 左侧引导区：注册完成 → 补充偏好 → 返回登录
└── 右侧表单卡片
    ├── el-radio-group (gender)
    ├── el-checkbox-group (tags)
    └── el-button (完成并返回登录)
```

**交互流程**：
1. `LoginView.vue` 注册参会者成功后，`authStore.register()` 保存 token。
2. `router.push('/register-preferences')`。
3. 偏好页提交 `PUT /api/v1/user/profile`，请求体包含 `gender` 和 `tags`。
4. 成功后调用 `authStore.logout()` 清除临时 token，再 `router.replace('/login')`。

**调用的 API**：
- `PUT /api/v1/user/profile`

### 4.3 B端 - 数据大屏（DashboardView.vue）— 组员A

**路径**：`/b/dashboard`

**功能**：
- 展示核心指标卡片：活动状态、总售票量、累计签到人数、活动总数
- 图表展示：各活动售票比例饼图、近7天签到趋势折线图、男女比例饼图
- **各活动数据卡片列表**：以卡片形式展示所有活动的基本数据（总票数、已售、已签到），点击活动卡片跳转到对应活动的数据详情页
- 【AI 禁飞区】未开始活动的参会率预测展示

**设计说明**：
- 活动列表以卡片形式展示所有活动的基本数据
- 点击活动卡片跳转到 `/b/dashboard/event/:id` 数据详情页
- 数据详情页数量与活动数量一致，每个活动都有独立的数据详情页
- 数据详情页展示该活动的详细指标、图表和签到明细

**组件结构**：
```
DashboardView.vue
├── el-row (指标卡片)
│   ├── StatCard (活动状态: online/offline)
│   ├── StatCard (总售票量)
│   ├── StatCard (累计签到人数)
│   └── StatCard (活动总数)
├── el-row (图表区域)
│   ├── PieChart (各活动售票比例)
│   ├── LineChart (近7天签到趋势)
│   └── PieChart (男女比例)
├── el-card (各活动数据列表)
