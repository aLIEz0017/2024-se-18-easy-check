## 个人分工：活动 + 票务 + 推荐（含 2 个 AI禁飞区）

```
controller/
├── EventController.java         # 4.1 发布 / 4.2 列表 / 4.3 详情 / 4.4 更新 / 4.5 状态 / 4.6 删除 / 4.7 🔒 AI文案
├── TicketController.java        # 5.1 抢票 / 5.2 票夹 / 5.3 单票 / 5.4 签到 / 5.5 签到明细
└── RecommendController.java     # 7.1 🔒 活动推荐

service/
├── EventService.java / EventServiceImpl.java
├── TicketService.java / TicketServiceImpl.java
└── RecommendService.java / RecommendServiceImpl.java

dto/request/
├── CreateEventRequest.java
├── UpdateEventRequest.java
├── ChangeEventStatusRequest.java
├── PurchaseRequest.java
└── CheckinRequest.java

dto/response/
├── EventResponse.java
└── TicketResponse.java

【🔒 AI禁飞区】EventService 中调用 MockAiService.generateDescription()
【🔒 AI禁飞区】RecommendService 中调用 MockAiService.recommend()
```

> 说明：注册后偏好设置页依赖认证/用户模块的 `PUT /api/v1/user/profile` 写入 `gender/tags`，不属于本文档的「活动 + 票务 + 推荐」后端个人分工；推荐模块只读取用户已有 `tags` 参与排序或在缺失时降级为热度排序。
